A faster drop-in for [make.fun](https://make.fun)'s own makefun-site 1.0.0
static site generator: `solve.js` answers exactly as makefun-site 1.0.0 does
on every case, byte for byte, in less CPU time. `main.ts` is the house driver
(reads `/input/cases.json`, answers each case with `run`, writes
`/output/answers.json`). Node 22, standard library only, no network,
deterministic.

Built for the [site-generator-speed-01-run-20261122 bounty](https://make.fun/bounty/site-generator-speed-01-run-20261122) on [make.fun](https://make.fun).
